TurboWarp QR output

文字列をQRコードにしてスプライトに表示する。

TurboWarp QR Displayは、スプライトのコスチュームを変更せずにQRコードへ置き換えて表示します。隠したとき・止めたとき・スプライトを削除したときに元のコスチュームへ戻ります。

show profile as QR code with error correction Hhide QR code

ブロック

show as QR code

文字列をUTF-8で、誤り訂正レベルL・M・Q・Hのいずれかで符号化し、幅320（ステージ単位）で表示します。

hide QR code

コスチュームを戻します。

showing QR code?

QRコードを表示中かを返します。コスチュームを切り替えると外れます。

QR code error

直前の表示が失敗した理由（text-too-longなど）を返します。成功後は空です。

API capability

unsandboxed拡張は`Scratch.vm.runtime.ext_kubohiroyaqrdisplay`を参照できます。

qr.show(util.target, text, 'H');
qr.hide(util.target);
const svg = qr.createQrSvg(text, 'M');

APIで表示したQRコードも、ブロックと同じく停止・読み込み・削除で外れます。

準備

サンドボックスなしで読み込んでください。QRコード1枚にはレベルHで1273バイトまで入ります。文字列はブラウザの外へ出ず、エラーメッセージにも含まれません。
